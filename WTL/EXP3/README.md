# EXP - 3: Interactive To-Do List

### Aim

Develop an interactive To-Do List application using AI-assisted JavaScript coding.

## Features

- Add tasks with a priority and optional due date.
- Edit task details, mark tasks complete, and delete tasks.
- Filter the list by all, to-do, or completed tasks.
- Search task titles and clear all completed tasks.
- View task totals and completion progress.
- Save tasks in the browser with `localStorage` so they remain after refresh.
- Use the responsive layout on desktop and mobile screens.

## Run

Open [index.html](./index.html) in a modern web browser. No installation or build step is required.

The task list is stored only in the current browser and origin. Clearing browser storage or opening the app under a different origin starts a separate list.

## Files

- [index.html](./index.html) - page structure and task form.
- [style.css](./style.css) - responsive layout and visual styles.
- [script.js](./script.js) - task actions, filters, progress, and local storage.
